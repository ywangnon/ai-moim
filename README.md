# 🎄 Merry Christmas & Happy New Year - 크리스마스 원페이지 웹사이트

마법 같은 겨울밤의 분위기와 다채로운 인터랙션을 담은 **크리스마스 단일 페이지(One-Page) 웹사이트**입니다.  
별도의 빌드 도구, 프레임워크 또는 외부 미디어 파일 의존성 없이 `index.html` 파일 하나만 더블 클릭하면 브라우저에서 바로 실행됩니다.

---

## ✨ 주요 기능 및 특징

1. **❄️ 인터랙티브 눈 내림 (Canvas Snow & Aurora)**
   - 캔버스 기반의 자연스러운 눈 내림 애니메이션
   - 우측 상단 버튼을 통해 눈 내림 강도 조절 가능 (`보통` / `폭설` / `잔잔함`)
   - 몽환적인 겨울 오로라 빛 애니메이션

2. **🎅 밤하늘을 가로지르는 산타 & 썰매 (Flying Santa Animation)**
   - 우측 상단 **[🎅 산타 부르기]** 버튼 클릭 시 루돌프와 산타 썰매가 별빛 가루(Stardust)를 흩날리며 밤하늘을 비행
   - 45초마다 주기적으로 자동 비행 연출 및 맑은 종소리 효과음

3. **⏳ 실시간 크리스마스 D-Day 카운트다운**
   - 12월 25일 자정까지 남은 일수, 시간, 분, 초를 실시간 계산하여 표시

4. **🔔 Web Audio API 캐롤 오르골 & 모닥불 ASMR 플레이어**
   - 외부 MP3 파일 없이 웹 표준 Web Audio API로 합성된 감성적인 오르골 캐롤 연주
     - *징글벨 (Jingle Bells)*
     - *We Wish You a Merry Christmas*
     - *고요한 밤 거룩한 밤 (Silent Night)*
   - 타닥타닥 소리가 나는 포근한 모닥불(Fireplace) 앰비언트 사운드 토글
   - 하단 플레이어 바의 **음량 조절 슬라이더**로 편안하게 볼륨 조절 가능

5. **🎄 반짝이는 소원 트리 (Interactive Wish Tree)**
   - SVG로 정교하게 렌더링된 크리스마스 트리
   - 원하는 오너먼트 모양(🔴, ⭐, 🔔, 🎁, 🧦, ⛄)을 골라 나만의 소원 남기기
   - 트리에 걸린 오너먼트를 클릭하면 소원 카드 팝업 모달 확인 가능
   - 작성한 소원은 브라우저 로컬 스토리지(`localStorage`)에 저장되어 새로고침 후에도 유지
   - 트리 꼭대기의 큰 별(⭐)을 누르면 서프라이즈 축하 효과 및 사운드 발생!

6. **🎁 산타의 깜짝 선물 상자 (Lucky Box)**
   - 3D 입체 선물 상자를 클릭하면 뚜껑이 열리며 화려한 폭죽(컨페티) 효과 연출
   - 따뜻한 덕담과 홀리데이 쿠폰(핫초코 1회권 등) 랜덤 증정

7. **📅 25일 크리스마스 어드벤트 캘린더 (Advent Calendar)**
   - 12월 1일부터 25일까지 매일 문을 하나씩 여는 3D 카드 뒤집기 인터랙션
   - 날짜마다 숨겨진 겨울 꿀팁, 추천 캐롤, 크리스마스 레시피, 감동 메시지 오픈
   - 열린 도어는 `localStorage`에 자동 저장되며 언제든 리셋 가능

8. **💌 나만의 크리스마스 엽서 만들기 & 이미지 다운로드**
   - 4가지 무드 테마 배경 (미드나잇 블루, 클래식 크림슨, 포레스트 그린, 앤틱 골드)
   - 받는 사람, 전하는 메시지, 보내는 사람 실시간 미리보기
   - **[완성된 카드 이미지 다운로드]** 클릭 시 고화질 PNG 엽서 이미지 즉시 저장

9. **🕹️ 루돌프의 선물 바구니 미니게임 (Gift Catcher)**
   - 마우스나 모바일 터치로 썰매 바구니를 좌우로 움직여 선물(🎁)과 별(⭐) 획득
   - 장애물 얼음 폭탄(💣)을 피해 점수를 올리고 최고 기록에 도전

10. **💬 감성 명언 & 캐롤 문구 롤링 캐러셀**
   - 연말의 따스함을 전하는 명언들이 7초마다 부드럽게 전환

---

## 🚀 실행 방법

### 방법 1. 바로 열기 (가장 간단)
- 탐색기/파인더에서 `index.html` 파일을 더블 클릭하여 Chrome, Safari, Edge 등 원하는 브라우저로 엽니다.

### 방법 2. 로컬 웹 서버로 열기 (선택)
터미널에서 아래 명령어로 간이 서버를 띄워 접속할 수 있습니다:
```bash
# Python 3
python3 -m http.server 8080
```
브라우저 주소창에 `http://localhost:8080`을 입력하여 접속합니다.

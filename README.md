# 👑 어벤져스: 둠스데이 (Avengers: Doomsday) 대한민국 개봉일 카운트다운

2026년 12월 16일(수) 대한민국 전 세계 최초 극장 개봉을 기념하는 **<어벤져스: 둠스데이>** 실시간 인터랙티브 카운트다운 웹 애플리케이션입니다.  
별도의 빌드 도구 없이 `index.html`을 브라우저에서 바로 열거나 GitHub Pages로 즉시 배포할 수 있는 **제로 빌드(Zero-build) 모듈형 아키텍처**로 제작되었습니다.

---

## ✨ 주요 기능 및 특징

1. **⏳ 실시간 SF HUD 카운트다운 (2026. 12. 16 대한민국 대개봉)**
   - 2026년 12월 16일 자정(KST)까지 남은 일수, 시간, 분, 초를 실시간 계산하여 표시
   - 북미(12월 18일)보다 이틀 앞선 한국 최초 전야 개봉 카운트다운

2. **👑 닥터 둠(Victor von Doom) 3D 마스크 패럴랙스 인터랙션**
   - 마우스 커서의 움직임에 따라 3D 원근 각도로 회전하는 메탈릭 닥터 둠 마스크 SVG
   - 마스크 클릭 시 녹색 아크 리액터 파동 및 스파클 파티클 이펙트

3. **🌓 듀얼 테마 시스템 (우상단 프로토콜 스위치)**
   - **라트베리아 둠 모드**: 심연의 블랙과 네온 에메랄드 룬 마법 테마 (기본)
   - **스타크 테크 모드**: 아크 리액터 블루 & 홀로그램 테크 테마
   - `localStorage`를 통해 사용자가 선택한 테마 영구 기억

4. **⚖️ 멀티버스 생존자 판결기 (Who Will Survive?)**
   - 요원 코드명과 주력 히어로(아이언맨, 스파이더맨, 울버린, 닥터 스트레인지 등) 선택
   - 닥터 둠의 AI가 멀티버스 생존 확률(%)과 배틀월드 지정 임무를 판결
   - 원클릭 클립보드 복사로 SNS 및 메신저 공유 지원

5. **📂 기밀 배틀월드 아카이브 (Classified Dossiers)**
   - 개봉일까지 하나씩 열람하는 10개의 MCU 멀티버스 기밀 파일
   - 로버트 다우니 주니어 복귀 비화, 루소 형제 감독, 인커전 현상, 배틀월드 등 상세 모달 뷰어

6. **🌀 인커전 차원 균열 방어전 (30초 아케이드 미니게임)**
   - 캔버스 기반으로 쏟아지는 둠봇(🤖), 인커전 포탈(🌀), 인피니티 스톤(💎)을 타격하여 격추
   - 실시간 스코어 및 콤보 시스템 탑재

7. **🎵 Web Audio API 어벤져스 시그니처 사운드트랙 플레이어**
   - 외부 오디오 파일 없이 웹 브라우저 자체 Web Audio API로 합성된 웅장한 브라스 사운드
     - *⚔️ Avengers Assemble Theme (Alan Silvestri 스타일)*
     - *👑 Latveria: Doom's Throne Ambient (닥터 둠 앰비언스)*
   - 펄스 비주얼라이저 및 트랙 탐색 컨트롤

## 📁 디렉토리 구조 (모듈형 아키텍처)

```
ai-moim/
├── index.html                    # 시맨틱 구조 및 메타태그
├── css/
│   ├── base.css                  # 디자인 시스템 변수, 폰트, 리셋, 공통 스타일
│   ├── theme.css                 # 둠 vs 스타크 테크 듀얼 테마 및 우상단 스위치
│   ├── layout.css                # 네비게이션, HUD 헤더, 반응형 그리드
│   └── components.css            # 3D 마스크, 카운트다운, 아카이브, 미니게임 UI
├── js/
│   ├── countdown.js              # 2026.12.16 개봉 D-Day 타이머 연산
│   ├── theme.js                  # 우상단 듀얼 테마 토글 및 LocalStorage 동기화
│   ├── particles.js              # 캔버스 인커전 & 룬 마법 파티클 렌더링
│   ├── audio.js                  # Web Audio API 오케스트라 사운드 신디사이저
│   ├── mask3d.js                 # 3D 둠 마스크 마우스 시차 인터랙션
│   ├── survival-tester.js        # 생존자 판결기 알고리즘 및 클립보드 복사
│   ├── archives.js               # 기밀 배틀월드 파일 뷰어 및 모달 연동
│   ├── minigame.js               # 차원 균열 방어 30초 캔버스 미니게임
│   └── main.js                   # 전체 모듈 오케스트레이션
└── README.md
```

## 🚀 실행 방법

별도의 `npm install`이나 빌드 과정 없이, 웹 브라우저에서 `index.html`을 더블 클릭하여 바로 실행할 수 있습니다.
GitHub Pages 저장소 설정 시 전 세계 어디서든 정적 호스팅으로 접근 가능합니다.
